Line up your JSON.

A tiny, zero-dependency CLI that formats package.json and any other JSON file so the values sit in a neat column, without changing a single value.

package.json 

        


        

          
Zero dependencies
Nothing to audit. The whole package is under 9 kB.

          
Lossless
Big numbers, 1.50, 1e3 and escaped characters are copied exactly as written.

          
Safe
Invalid files are reported and left alone. Tidy files are never rewritten.

          
CI friendly
tabify --check exits with 1 when something needs formatting.

          
Wide-character aware
Chinese, Japanese, Korean and emoji keys line up too.

          
Typed API
format(text, options) with TypeScript types, for CommonJS and ESM.

        


        
Under the hood

        
    
          
  • 01
    A lossless parser. JSON.parse decides whether the file is valid, then a small scanner walks the text and keeps every value's original source. Formatting only ever changes whitespace.
    • 
          
  • 02
    Alignment measured on screen. Keys are measured in display columns, so a key like "名前" counts as four characters wide.
    • 
          
  • 03
    Only what matters lines up. Keys that open a nested block, such as "devDependencies": {, stay out of the column, so one long key doesn't push everything to the right.
    • 
          
  • 04
    Tested everywhere. 33 tests run on Linux, macOS and Windows with Node.js 18, 20, 22 and 24 on every push.
    •

Command line

        
Run it once with npx json-tabifier, or add it to your project with npm install --save-dev json-tabifier and use the tabify command.


# formats ./package.json
npx tabify

# every .json file under the current directory
npx tabify .

# the given files, and .json files in the given directories
npx tabify tsconfig.json config/

# changes nothing; exit code 1 if a file needs formatting
npx tabify --check


        
Options

        

          

            
OptionDescription

            
              
-c, --checkDon't write anything; exit with 1 if a file needs formatting

              
--config <file>Read options from <file> instead of ./json-tabifier.json

              
-q, --quietOnly print errors

              
-h, --helpShow the help

              
-v, --versionShow the version number

            
          

        

        
Exit codes: 0 everything is fine, 1 files need formatting (with --check), 2 an error occurred.


        
Configuration

        
Put a json-tabifier.json file in the directory you run tabify from. Every option is optional; these are the defaults:


{
  "onlyPackageJson": true,
  "maxKeyLength"   : 0,
  "indent"         : 2,
  "excludes"       : ["node_modules","package-lock.json"]
}

        

          

            
OptionDescription

            
              
onlyPackageJsonWhen no paths are given: true formats only ./package.json, false every .json file below the current directory.

              
maxKeyLengthKeys longer than this aren't aligned and don't widen the column. 0 means no limit.

              
indentSpaces per nesting level (1–10), or "tab".

              
excludesRegular expressions matched against paths relative to the current directory, with / separators.

            
          

        

      


      
      

        
API

        
The formatter is a single function. It works with require and import, and ships its own TypeScript types.


import { format } from 'json-tabifier'
// or: const { format } = require('json-tabifier')

format('{"a":1,"bbb":2}')
// '{\n  "a"  : 1,\n  "bbb": 2\n}\n'

format(text, { maxKeyLength: 20, indent: 4 })

        
format(text, options?)

        
Takes JSON text and returns the formatted text, ending with a newline. A byte order mark and Windows line endings are kept. Throws a SyntaxError if the text isn't valid JSON.
